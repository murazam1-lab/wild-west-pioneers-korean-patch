# Wild West Pioneers 비공식 한국어 패치

[English README](README.md)

스팀 게임 *Wild West Pioneers*(Unity 6, IL2CPP)를 한국어로 옮긴 비공식 팬 번역 프로젝트입니다. 이 저장소에는 작업 과정 정리와 직접 만든 도구만 들어 있습니다. 게임 파일, 추출한 게임 텍스트, 완성된 번역본은 포함하지 않습니다.

## 요약

| | |
|---|---|
| 엔진 | Unity 6000.1.17f1, IL2CPP |
| 텍스트 시스템 | I2 Localization, TextMeshPro, UI Toolkit |
| 번역 표 | I2 7,820항목 (번역 대상 7,262문장 전면 검수) |
| 번역 표 밖 고정 문구 | 179곳 (78종) 찾아서 번역 |
| 수정한 파일 | `resources.assets`, `level0/6/8/9/11`, `sharedassets0/6/11.assets` |
| 대상 빌드 | Steam 빌드 26485589 (2026-11-07) |
| 작업 차수 | 5차 (2026-11-01 ~ 2026-11-08) |

## 작업 내용

### 번역
- **번역 지침과 용어집 정리** ([docs/style-guide.ko.md](docs/style-guide.ko.md)): 글의 종류마다 말투를 정했습니다. UI 레이블은 짧은 명사형, 설명·도움말은 합니다체, 퀘스트 목표는 명사형 종결, 대사는 인물별 말투를 씁니다. 건물·자원·지명·인물·퀘스트 제목 약 300개를 통일했습니다.
- **조사 처리**: 아이콘이나 변수 바로 뒤에는 받침에 따라 바뀌는 조사가 오지 않게 문장 구조를 바꿨습니다.
- **차수별 작업**
  - 1~3차: 로컬 기계번역 모델([quickmt](https://huggingface.co/quickmt/quickmt-en-ko)) 초벌 번역에 일부 수동 수정을 더했습니다.
  - 4차: 지침에 맞춰 AI(LLM)의 도움을 받아 전 문장을 다시 검수했고, 3,965항목을 고쳤습니다. 고치기 전후 예시는 [docs/examples.md](docs/examples.md)에 있습니다.
- **자동 검사**: 모든 문장을 검사했습니다. 아이콘·변수·서식 태그·줄바꿈 개수가 원문과 같은지, 용어집대로 썼는지, 영어가 남았는지, 글꼴에 없는 글자를 쓰지 않았는지 확인합니다.

### 기술
- **I2 Localization 바이너리**: 바이너리 데이터를 직접 읽고 다시 쓰는 도구를 만들었습니다. 다른 언어와 키는 그대로 두고 한 언어 칸만 바꿉니다. 온라인 시트 동기화가 패치를 덮어쓰지 않도록 꺼 두었습니다.
- **글꼴**
  - 게임에 들어 있는 Source Han Serif를 TextMeshPro 전역 대체 글꼴로 연결했습니다.
  - 한글 줄바꿈 규칙과 다중 아틀라스를 켰습니다.
  - UI Toolkit 글꼴도 같은 글꼴로 연결했습니다.
  - 퀘스트 패널에서 한글이 네모로 깨지던 문제는 파일 간 대체 글꼴 참조를 추가해 고쳤습니다.
- **고정 문구**: 모든 씬과 에셋에서 번역 시스템 밖에 박힌 영어 문구를 찾았습니다. 표시용 스크립트만 참조하는 칸만 골라서 바꿨고, 코드가 덮어쓰는 칸과 개발용 화면은 제외했습니다.
- **저장 정확도**
  - UnityPy는 객체를 8바이트 단위로 정렬해 저장하지만 원본은 16바이트 단위라, 원본과 같게 맞췄습니다.
  - 저장한 뒤 모든 객체를 원본과 대조해서, 의도한 객체만 바뀌었는지 확인합니다.
  - 파일 헤더·타입 표·외부 참조·객체 순서도 원본과 비교합니다.
- **설치와 복구**
  - 원본을 백업하고 SHA-256 해시로 검증합니다.
  - 게임이 실행 중이면 멈춥니다.
  - 게임이 업데이트되어 파일이 달라졌으면 적용과 복구를 모두 중단합니다.

## 한계
- 게임 빌드 하나에 맞춰 만든 패치입니다. 스팀 업데이트가 오면 패치가 지워지고, 새 버전에 맞춰 다시 만들어야 합니다.
- `GameAssembly.dll` 안의 영어 문자열(주로 로그·오류 메시지)은 고치지 않았습니다.
- 5차 변경분은 파일과 객체 단위로만 검증했습니다. 실제 게임 화면에서 모두 확인하지는 않았습니다.

## 고지
비공식 팬 번역입니다. *Wild West Pioneers*의 개발사·퍼블리셔와 관계가 없습니다. 게임 콘텐츠의 권리는 개발사와 퍼블리셔에 있습니다.
